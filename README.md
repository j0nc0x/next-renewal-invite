# next-renewal-invite

The page that next renewal's Invite links open, served by GitHub Pages:

    https://j0nc0x.github.io/next-renewal-invite/?code=<code>[&app=dev]

Messaging apps only make `https://` links tappable, so Invites link here. The page shows the code and an
**Open in next renewal** button that opens the app's Join a List screen (or the Play Store if the app isn't
installed). `app=dev` targets the development build.

The page holds no secrets: it only reads the code from the address. The app itself lives in a private repo.
